# Artigos do mestrado

Cada artigo tem uma pasta própria com:

- `PROJETO.md` — ficha do projeto: pergunta, objetivo, lentes, método, mapa do material, diagnóstico, pendências, decisões e cronograma.
- `diario.md` — registro de cada sessão de trabalho.

Para trabalhar em um artigo, use a skill `/artigo-mestrado` (em `.claude/skills/artigo-mestrado/`). Para começar um novo, copie `_modelo/` para `artigos/<nome-do-artigo>/`.
