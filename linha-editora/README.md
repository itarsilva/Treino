# Linha Editora — Gestão

Planilha única (`Linha_Editora_Gestao.xlsx`) que organiza a operação da editora e funciona como um CRM simples.

| Aba | Para que serve |
|---|---|
| **Painel** | Visão geral: catálogo, finanças, CRM, receita por canal e funil |
| **Como usar** | Legenda de cores e passo a passo |
| **Catálogo** | Títulos por ISBN: preço, custo, margem, tiragem, vendidos, estoque |
| **Autores** | Contratos, % de royalties, adiantamento, royalties gerados e saldo a pagar |
| **Produção** | Cronograma editorial por etapa (edição → revisão → diagramação → capa → gráfica) com atrasos |
| **CRM_Contatos** | Livrarias, distribuidoras, imprensa, influenciadores, escolas, leitores |
| **CRM_Interações** | Histórico de cada contato (alimenta "última interação") |
| **CRM_Pipeline** | Oportunidades de venda B2B com etapa, probabilidade e valor ponderado |
| **Vendas** | Pedidos por ISBN e canal — alimenta estoque, royalties e Painel |
| **Financeiro** | Fluxo de caixa (receitas e despesas por categoria) |
| **Listas** | Opções dos menus suspensos e probabilidades do funil |

**Cores:** azul = você preenche · preto = fórmula · verde = puxado de outra aba.
As linhas de "Exemplo" mostram o formato esperado; apague-as ao começar a usar.
